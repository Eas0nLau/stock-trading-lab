# 龙虎榜溢价分析

## 用途

该功能用于复盘龙虎榜营业部的历史表现，不是自动交易信号。系统根据营业部历史买入记录和后续行情，计算样本充足席位的平均短线收益，并筛选当前关联的股票。

## 使用方法

1. 打开前端的“龙虎榜溢价”页面。
2. 输入开始日期和最新日期，格式为 `YYYYMMDD`。
3. 点击“采集并分析”。
4. 页面会显示采集阶段：龙虎榜、营业部目录、营业部历史、溢价分析。
5. 任务完成后查看选中的股票代码和结果数量。

页面请求是异步任务，不需要手动运行旧 Python 脚本。重复点击会被任务锁阻止，已有任务完成或失败后才能重新发起。

## 数据流程

页面触发后按顺序执行：

1. 采集日期区间内的龙虎榜页面。
2. 更新营业部目录。
3. 更新营业部历史上榜记录。
4. 使用 canonical 数据计算溢价结果。

采集失败会停止后续阶段，页面显示失败阶段和错误信息。分析阶段只读取数据库，不再次访问外部页面。

## 数据位置

原始数据保存在 MySQL：

| 数据 | 表 |
|---|---|
| 龙虎榜明细、买卖席位 | `dragon_tiger` |
| 营业部历史上榜记录 | `broker_listing_history` |
| 营业部目录 | `brokers` |
| 营业部统计 | `broker_top_stats` |
| 后续行情 | `daily_quotes` |

分析结果是本次请求的返回结果，不单独写入结果表。页面关闭后，可重新用相同日期区间分析。

## 接口

```text
POST /api/v1/dragon-tiger/collection-jobs
GET  /api/v1/dragon-tiger/collection-jobs/{jobId}
GET  /api/v1/dragon-tiger/premium?start_date=YYYYMMDD&latest_date=YYYYMMDD
```

旧入口 `游资溢价分析/溢价分析.py` 使用硬编码日期直接返回 Python 列表；旧采集脚本也已退役，不再作为产品触发方式。
